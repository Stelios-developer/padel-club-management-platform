# Πραγματικοί έλεγχοι ολόκληρου του συστήματος

Το `scripts/e2e.mjs` χρησιμοποιεί πραγματικό HTTP μέσω Nginx/API Gateway, authorization code + S256 PKCE στο Keycloak, τις PostgreSQL βάσεις των υπηρεσιών, RabbitMQ και SMTP στο Mailpit. Δεν χρησιμοποιεί H2, mocked downstream υπηρεσίες ή τη λειτουργία επίδειξης.

Για πραγματικές ενέργειες μέσα από το web περιβάλλον, το `node scripts/user-journey.mjs` καλύπτει τη διαδρομή νέου μέλους και υποδοχής με Playwright, πραγματικό OIDC και προσωρινούς λογαριασμούς. [Οδηγίες, αποτελέσματα και όρια του ελέγχου χρήστη](USER-VERIFICATION.md).

## Εκτέλεση

Απαιτούνται Docker με Linux containers και Node.js 22+. Οι θύρες 3000, 8080, 8081, 8025, 8761 και 15672 πρέπει να είναι ελεύθερες. Σταμάτησε το standalone `node web/server.cjs` ή άλλο Padel Compose project που χρησιμοποιεί τις ίδιες θύρες.

```powershell
.\scripts\e2e.ps1
```

Το script χτίζει και ξεκινά το **ξεχωριστό Compose project `padel-e2e`**, τρέχει όλες τις δοκιμές, αποθηκεύει αποτελέσματα και σταματά τα δοκιμαστικά containers. Τα volumes διατηρούνται. Για υπάρχουσες εικόνες ή για να παραμείνει η εφαρμογή διαθέσιμη:

```powershell
.\scripts\e2e.ps1 -SkipBuild -KeepRunning
```

Σε Linux/CI ή για ξεχωριστά βήματα:

```sh
docker compose --env-file .env.example -p padel-e2e up -d --build --wait --wait-timeout 480
node scripts/e2e.mjs --resilience
docker compose --env-file .env.example -p padel-e2e down
```

Το `node scripts/e2e.mjs` χωρίς `--resilience` εκτελεί τις λειτουργικές δοκιμές χωρίς διακοπές/restarts. Το script υποστηρίζει αποκλειστικά το `padel-e2e`, τις τοπικές διευθύνσεις και τα development credentials του `.env.example`. Δεν προορίζεται για εκτέλεση σε production.

Η αρχική εγγραφή/διάδοση στο Eureka είναι ασύγχρονη. Η σουίτα περιμένει τις διαδρομές Gateway και έως 90 δευτερόλεπτα για το πρώτο downstream access check όταν επιστρέφεται 503· τα υπόλοιπα status codes ελέγχονται κανονικά. Το container liveness από μόνο του δεν εγγυάται ότι έχει διαδοθεί ήδη όλο το registry.

Μετά από εσκεμμένο restart, η σουίτα περιμένει επιτυχή ανάγνωση πριν ελέγξει το replay. Ο helper νέας κράτησης επαναλαμβάνει προσωρινές 5xx/αποτυχίες σύνδεσης έως 180 δευτερόλεπτα με το **ίδιο** Idempotency-Key· απαιτεί τελική επιτυχία και ελέγχει την πραγματική βάση/outbox. Τα οκτώ ταυτόχρονα αιτήματα idempotency ελέγχονται απευθείας, χωρίς retry που θα έκρυβε αποτυχία τους.

## Κάλυψη

Η ενότητα `e2e/padel.mjs`, που καλείται από την ίδια σουίτα, επαληθεύει τον κατάλογο παικτών χωρίς contact details, τις προσκλήσεις/συμμετοχές, concurrent αλλαγές τελευταίας θέσης, το προσωπικό ημερολόγιο και SQL exclusion ανά παίκτη. Ελέγχει επίσης deduplicated αναμονή/in-app delivery χωρίς αυτόματη κράτηση, εβδομαδιαία idempotency και rollback σειράς στη δεύτερη εβδομάδα. Τα σχετικά fixtures συμπεριλαμβάνονται στον κοινό καθαρισμό.

Η `e2e/reception.mjs` προσθέτει δέκα σενάρια: V7/staff-only πρόσβαση, αναζήτηση μελών, εβδομαδιαίο ημερολόγιο, rollback μεταφοράς, συγκρούσεις/επιλεξιμότητα συμμετεχόντων, οκτώ ταυτόχρονα retries και ειδοποίηση αναμονής, δύο ανταγωνιστικές μεταφορές, replay/history μετά από restart, οκτώ ταυτόχρονες παρουσίες, διορθώσεις/παράθυρα/διατήρηση μετά από ακύρωση. Το replay μετά από restart ελέγχει σταθερό fingerprint ανεξάρτητα από τη σειρά iteration των maps σε νέο JVM. Η πλήρης σουίτα με `--resilience` περιλαμβάνει **60 σενάρια**.

- Πραγματικό Keycloak login, issuer/audience/roles, υποχρεωτικό PKCE, λάθος verifier, απαγόρευση επαναχρησιμοποίησης code και απενεργοποιημένο password grant για το web client.
- Refresh token και απόρριψη ανώνυμων/αλλοιωμένων JWT από το πραγματικό gateway.
- Onboarding και email από την ταυτότητα, με ανεξάρτητη επιβεβαίωση αποθήκευσης στην PostgreSQL.
- Ownership και staff-only δικαιώματα σε διαφορετικές υπηρεσίες.
- Ενεργοποίηση/ακύρωση συνδρομής και επίδραση στις κρατήσεις και στην είσοδο.
- Idempotency σε πραγματική PostgreSQL: οκτώ ταυτόχρονες ενεργοποιήσεις συνδρομής ή κρατήσεις με ίδιο κλειδί επιστρέφουν οκτώ ίδιες επιτυχίες και αποθηκεύουν μία εγγραφή/ειδοποίηση. Ελέγχονται UUID headers, αλλαγή payload, rollback αποτυχημένου αιτήματος, απομόνωση χρήστη και replay μετά από ακύρωση.
- Οκτώ ταυτόχρονα αιτήματα για το ίδιο γήπεδο/ώρα: μία επιτυχία και επτά conflicts, με έλεγχο πραγματικής βάσης.
- Διαθεσιμότητα, διαδοχικές ώρες, απενεργοποιημένο μέλος/γήπεδο, ακύρωση και επανακράτηση.
- PostgreSQL exclusion constraint: επιβεβαίωση Flyway V4/GiST, απευθείας SQL με ίσα/μερικώς επικαλυπτόμενα/εσωτερικά διαστήματα και ισοδύναμα timezone offsets, ασφαλή INSERT σε διαδοχικές ώρες/άλλο γήπεδο, απορρίψεις UPDATE και επανενεργοποίησης, και οκτώ ταυτόχρονες SQL συναλλαγές που παρακάμπτουν τον application lock.
- Όλες οι domain API δοκιμές στέλνουν `Accept-Language: el-GR`. Επιπλέον ελέγχονται 90λεπτες κρατήσεις με ελληνική και βρετανική γλώσσα: οι ημερομηνίες μένουν ISO στην επικοινωνία Feign, ανεξάρτητα από locale.
- Έγκυρη/πρόωρη/ακυρωμένη είσοδος, late cancellation και staff override. Για τις χρονικά ευαίσθητες δοκιμές, αποκλειστικά οι κρατήσεις του test μετακινούνται στη βάση σε συγκεκριμένο παράθυρο γύρω από το `now()`· το ρολόι του υπολογιστή δεν αλλάζει.
- Outbox → RabbitMQ → persisted notification → SMTP/Mailpit και επαναποστολή του ίδιου event ID.
- Διατήρηση κράτησης μετά από restart booking-service.
- Διατήρηση του αποθηκευμένου idempotency response μετά από restart booking-service και subscription-service, χωρίς νέα εγγραφή ή επανενεργοποίηση.
- Αναδημιουργία του Gateway χωρίς restart του υπάρχοντος Nginx, με επιβεβαίωση ότι οι πραγματικές API κλήσεις εξακολουθούν να λειτουργούν.
- Διακοπή RabbitMQ: η κράτηση παραμένει αποθηκευμένη, το event παραμένει στο outbox και παραδίδεται μετά την επαναφορά.
- Διακοπή SMTP: αποθηκεύεται αποτυχημένη προσπάθεια/PENDING retry και επιβεβαιώνεται παράδοση μετά την επαναφορά, με τουλάχιστον δύο προσπάθειες.

Δημιουργούνται μοναδικές προσωρινές ταυτότητες Keycloak για μέλος, δεύτερο μέλος και διαχειριστή. Στο τέλος ακυρώνονται οι κρατήσεις/συνδρομές αυτού του run και αφαιρούνται αυτές οι ταυτότητες. Τα audit, προφίλ και ειδοποιήσεις παραμένουν στα **δοκιμαστικά** volumes ως αποδεικτικά. Δεν διαγράφονται volumes ή δεδομένα άλλων projects. Τα email παραμένουν στο τοπικό Mailpit και δεν στέλνονται σε εξωτερικούς παραλήπτες.

Δημιουργούνται επίσης δύο προσωρινοί OIDC clients για απόρριψη πραγματικών tokens με λάθος audience ή χωρίς `sub`. Αφαιρούνται στο τέλος του run.

Οι πρόσθετες SQL δοκιμές του [database constraint](BOOKING-CONSTRAINT.md) δημιουργούν αποκλειστικά καταγεγραμμένα UUID fixtures στη μελλοντική ημερομηνία 10/01/2035, εκτός API booking window. Στο τέλος ακυρώνονται με άμεσο UPDATE των συγκεκριμένων UUIDs. Δεν παράγουν outbox events/email και δεν επηρεάζουν ώρες κανονικών δοκιμών.

### Ήδη εισαγμένο realm από την αρχική έκδοση

Το Keycloak 26.7 χρειάζεται το default client scope `basic` για το `sub`. Η αρχική ρύθμιση το παρέλειπε. Το ενημερωμένο realm JSON το περιλαμβάνει, αλλά το `--import-realm` δεν ενημερώνει realm που υπάρχει ήδη στη βάση. Σε υπάρχουσα τοπική εγκατάσταση, πρόσθεσέ το χωρίς διαγραφή δεδομένων:

```sh
node scripts/repair-keycloak-basic.mjs
```

Το helper χρησιμοποιεί τις τοπικές admin τιμές του `.env`, προσθέτει μόνο το scope `basic` στο `padel-web` και διατηρεί τα υπόλοιπα scopes. Για το δοκιμαστικό project που χρησιμοποιεί `.env.example`: `node scripts/repair-keycloak-basic.mjs --example-env`. Μετά απαιτείται νέα σύνδεση.

## Αποτελέσματα και όρια

Το `test-results/e2e.json` περιέχει ονόματα σεναρίων, αποτέλεσμα και διάρκεια, χωρίς access/refresh tokens ή κωδικούς. Ο PowerShell wrapper αποθηκεύει επίσης κατάσταση containers και logs. Η διεργασία επιστρέφει μη μηδενικό exit code σε αποτυχία και ο runner επαναφέρει RabbitMQ/Mailpit σε `finally` μετά τις δοκιμές διακοπών.

Το GitHub Actions job `e2e` εκτελεί την ίδια σουίτα και αποθηκεύει τα αποτελέσματα ως artifact. Η τοπική επιτυχία δεν επιβεβαιώνει εκτέλεση του workflow στο GitHub.

Η σουίτα δεν αντικαθιστά browser UI testing, load testing, penetration testing, έλεγχο monitoring ή deployment σε Kubernetes. Η επαναποστολή event ID ελέγχει deduplication μετά το commit, όχι ακριβώς μία αποστολή email σε κάθε πιθανό crash.
